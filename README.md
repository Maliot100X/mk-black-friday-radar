# 🔥 MK Black Friday Radar

AI-powered deal discovery platform for **North Macedonia** (Северна Македонија).

## Features

- ✅ AI Agents for deal discovery
- ✅ Real MKD (денар) prices from North Macedonia stores
- ✅ User authentication with JWT
- ✅ QR Code membership system
- ✅ Map radar (coming soon)
- ✅ Bilingual: Macedonian (MK) & Albanian (AL)
- ✅ Mobile app for Android
- ✅ Web dashboard

## Tech Stack

- **Backend**: FastAPI + PostgreSQL + Redis
- **Frontend**: Next.js + Tailwind CSS
- **Mobile**: React Native + Expo
- **AI**: Fireworks AI (Kimi K2.5 Turbo)

## Quick Start

```bash
# Backend
cd backend
pip install -r requirements.txt
python main.py

# Frontend
cd frontend
npm install
npm run dev
```
